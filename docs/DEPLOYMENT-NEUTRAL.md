# Hosting-neutral deployment guide (PresetHub 3.25.6 hardened)

## Runtime
- Node.js 20.x
- Start command: `npm start`
- Install command: `npm install` (or `npm ci` after lockfiles are generated)
- Health checks: `/healthz` (HTTP 200; inspect `database` field)
- Set the service working directory to the repository root.

## Required environment
Set `NODE_ENV=production`, `CLIENT_URL` to the canonical HTTPS site origin, `MONGODB_URI`, and a random `JWT_SECRET` of at least 32 characters. Set `TRUST_PROXY_HOPS` to the exact number of trusted reverse proxies between the internet and Node. Do not blindly copy a provider-specific value.

## Persistent data
PresetHub stores uploaded media in MongoDB GridFS (`presethub_media`). Backups generated by the app are local files; configure encrypted off-site backups and periodically test restores. Ensure Atlas network access permits only the hosting provider's outbound addresses where practical.

## Payments
Keep existing Cashfree, PhonePe and legacy Youpi routes. Configure only the gateway credentials actually used. Use sandbox credentials first, verify webhook URLs and signatures, then switch to production credentials. Never commit gateway secrets. Ensure the gateway webhook can reach `/api/payments/<provider>/webhook` over HTTPS.

## Admin
Do not rely on startup to grant admin privileges. Use the explicit `npm run create-admin` command with a dedicated admin email and a password of at least 12 characters. Existing non-admin accounts are never promoted automatically.

## Release checklist
1. Configure environment variables and MongoDB.
2. Install dependencies and run `npm run preflight`, `npm test`, and `npm audit`.
3. Verify login, upload, preview, paid download, refunds/payouts, and each configured payment provider in sandbox.
4. Verify HTTPS, trusted proxy count, CORS origin, webhook callbacks, backup export and restore.
