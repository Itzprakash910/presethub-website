How to import presets into Lightroom
Lightroom CC (Desktop)

File → Import Profiles → .dng फ़ाइल चुनें → Import

Lightroom Classic

Develop Mode → Presets Panel → "..." → Import Presets → .xmp चुनें

Lightroom Mobile

Presets → "..." → Import Presets → फ़ाइल चुनें
