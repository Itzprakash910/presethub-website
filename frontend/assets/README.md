# PresetHub — Icons & Logos Pack

This pack is aligned to the current PresetHub project assets and its existing Font Awesome class names. The brand visual is based on the PresetHub P mark and project palette.

## Brand
- `brand/presethub-mark.svg` — main P mark
- `brand/presethub-wordmark.svg` — PresetHub wordmark
- `brand/presethub-logo.svg` — full logo
- PNG variants in `brand/` for favicon/PWA/social use
- `source-assets/` contains the existing project logo/icon files copied from the supplied project ZIP

## Project icon naming
Filenames intentionally follow the project classes, e.g. `fa-search.svg` for `<i class="fas fa-search">` and `fab-instagram.svg` for `<i class="fab fa-instagram">`.

See `icons/icons-index.json` and `ASSET-MANIFEST.json` for the complete mapping.
