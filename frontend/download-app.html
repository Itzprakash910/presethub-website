PresetHub

Install PresetHub

PresetHub is a Progressive Web App. You can install it on Android, iPhone, Windows, Mac or ChromeOS without an APK.

Open PresetHub

Android

Open PresetHub in Chrome → menu ⋮ → Install app or Add to Home screen.

iPhone/iPad

Open in Safari → Share → Add to Home Screen.

APK

For a native APK, this project includes the PWA-ready web app. A real signed APK must be built and signed separately; this page never serves a fake or unsigned “APK” file.
